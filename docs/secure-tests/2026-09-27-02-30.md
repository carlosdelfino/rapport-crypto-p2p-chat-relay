## 4. Provas / evidências

- `npm run typecheck`: aprovado (0 erros).
- `npm audit`: 0 vulnerabilidades.
- `git diff --check`: aprovado.
- `npm run test:e2e`: **44/44 testes** passando (chromium + mobile-chromium), incluindo:
  - fixture que intercepta e bloqueia todo tráfego externo (apenas `www.googletagmanager.com` mockado);
  - asserção de zero `console.error`/`pageerror` em happy path;
  - asserção de não-redundância da seção "Páginas" e de presença dos novos links;
  - sem `waitForTimeout`; locators por role/texto semântico.
- Busca por `private_key`, `password`, `secret`, `api_key`, blocos PEM, `eval(`, `Function(`, `dangerouslySetInnerHTML` e hex de 64 chars nos arquivos alterados: nenhum resultado.
- Flake observado e descartado: `e2e/tokens.spec.ts` "descreve o contexto de uso" excedeu 30s uma vez sob paralelismo de 4 workers no projeto mobile; passou isolado (11.6s) e na reexecução completa (19.0s). Comportamento de timing, não de produto.

## 5. Mitigações aplicadas

- Páginas novas sem JavaScript próprio — superfície de injeção minimizada.
- Tabela de comandos com quebra de texto segura em viewports estreitas.
- Sitemap e cache consistentes entre `public/` e o template de regeneração (`build-android-apk.ts`), evitando divergência em futuros deploys de APK.
