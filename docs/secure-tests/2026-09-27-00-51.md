| ID | Severidade | Categoria | Localização | Descrição | Evidência |

| SC-001 | Informativa | Path traversal | `scripts/static-server.mjs` | O servidor estático normaliza o caminho e rejeita rotas fora de `public/`, sem directory listing. | Verificação de prefixo `PUBLIC_DIR` + teste E2E de 404 em rota inexistente. |
| SC-002 | Informativa | Conteúdo público | `public/tokens/index.html` | A página é 100% estática (sem JS de renderização, sem chamadas externas além do gtag.js já existente nas demais páginas). | SC-003 | Informativa | Canal de browser | `playwright.config.ts` | `channel: 'chrome'` usa o Google Chrome do sistema porque o CDN da Playwright está inacessível nesta máquina (timeout). Sem download de binário de fonte alternativa. | Falha de `npx playwright install` documentada; fallback para Chrome instalado em `/usr/bin/google-chrome`. |

## 5. Mitigações aplicadas

- Página `/tokens` sem JavaScript próprio — superfície de injeção minimizada (sem `innerHTML`/template dinâmico).
- Servidor de E2E com proteção contra path traversal e sem directory listing.
- Artifacts do Playwright (`playwright-report/`, `test-results/`) adicionados ao `.gitignore`.
- Cache `/tokens` em `vercel.json` com `s-maxage=300` igual ao padrão `/stats` e `/escrow`.
