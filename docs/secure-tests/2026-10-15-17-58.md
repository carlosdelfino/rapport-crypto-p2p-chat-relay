## 4. Provas / evidências

- `grep -c "fbevents.js"` em `public/`: 21 ocorrências, uma por página.
- `fbq('init', '1757670742628895')` presente nas 21 páginas e no template de
  `renderInstallPage()`.
- `npm run typecheck`: aprovado (0 erros).
- `npm run test:e2e`: suite completa aprovada; higiene de runtime não acusa
  `connect.facebook.net`/`www.facebook.com` como externos não mockados.
- Busca por `private_key`, `PRIVATE_KEY`, `password`, `secret`, `api_key`,
  blocos `BEGIN`, `eval(`, `Function(`, `dangerouslySetInnerHTML` e `0x` + 64
  hex no diff: nenhum resultado.
- Nenhuma CSP é servida (`vercel.json` não define `Content-Security-Policy`), então o pixel não é bloqueado — e nenhuma política foi relaxada.

## 5. Mitigações aplicadas

- Tracker limitado ao evento padrão `PageView`; nenhum evento customizado nem parâmetro de usuário é enviado.
- Fallback `<noscript>` mantido para usuários sem JavaScript (mesmo comportamento do gtag).
- Allowlist E2E explícita — qualquer domínio externo novo fora dos três permitidos continua reprovando a suite.
- Template de regeneração de `/install` atualizado junto com o HTML gerado, evitando divergência em futuros deploys de APK.
